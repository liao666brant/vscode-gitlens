# WeGit

> 小而美的 Git 工具，专注 VS Code 里的本地 Git 工作流。

WeGit 是从上游 MIT 代码清理而来的社区版工具，由 liao666brant 维护。它保留常用 Git 能力，去掉商业版、AI、Pro 入口和冗余功能，让扩展更轻、更直接。

## 功能

- 查看提交、分支、标签、stash 和仓库状态
- 浏览文件历史、行历史和提交详情
- 比较分支、标签、提交与工作区更改
- 使用文件 blame、changes、heatmap 注释理解代码变更
- 使用交互式 Rebase 编辑器整理提交
- 使用 Worktrees 并行处理多个本地分支

## 开发

```bash
pnpm install
pnpm run build:quick
pnpm run check
```
